# Cover Font (Comic Sans MS)

For a friendlier cover look, place **Comic Sans MS** here:

- `Comic_Sans_MS.ttf`

**Install options:**

- **Ubuntu/Debian:** `sudo apt install ttf-mscorefonts-installer`
  - Font will be at `/usr/share/fonts/truetype/msttcorefonts/`
- **Manual:** Download from [Microsoft Typography](https://learn.microsoft.com/en-us/typography/font-list/comic-sans-ms) and copy to this folder.

If not found, the cover falls back to DejaVu Sans.
